Kopi Senja POS
Prototipe kasir kafe satu layar
Kasir, Stok, HPP, Laba Bersih

Kelola kedai dari satu layar HP tanpa server

Aplikasi kasir kafe: pesan tunai & QRIS, kelola menu dan stok bahan, hitung HPP per porsi, catat biaya operasional, dan lihat laba bersih. Ada layar pemesan mandiri untuk pelanggan.

Akun demo admin & kasir Data tersimpan otomatis di browser Bisa diekspor JSON
Kasir Tunai & QRIS

Hitung kembalian tunai, tampilkan QRIS, dan cetak struk tiap transaksi.

Menu & Stok

Tambah menu, ubah harga, pantau stok, dan kurangi otomatis saat terjual.

HPP & Resep

Susun resep (BOM) bahan tiap menu; HPP dan margin terhitung otomatis.

Biaya Operasional & Laba Bersih

Catat sewa, listrik, gas, gaji; laba bersih = laba kotor dikurangi biaya operasional.

Multi Akun Kasir

Admin menambah akun kasir, mengedit nama dan sandi, serta menonaktifkan akun.

Layar Pelanggan Mandiri

Pelanggan memilih menu sendiri, memindai QRIS, lalu kasir mengonfirmasi pembayaran.

Cara kerja prototipe

1
Kasir / pelanggan pilih menu

Keranjang menampilkan total dan jumlah item.

2
Bayar tunai atau QRIS

Tunai dihitung kembaliannya; QRIS dikonfirmasi kasir.

3
Stok turun, laporan terupdate

HPP, laba kotor, biaya operasional, dan laba bersih tercatat.

Catatan data

Prototipe ini menyimpan data di localStorage per perangkat dan per browser (belum sinkron antar HP). Notifikasi pembayaran QRIS bersifat konfirmasi manual di prototipe; deteksi uang masuk otomatis memerlukan gateway pembayaran (mis. Midtrans/Xendit) dan backend. Gunakan tombol ekspor JSON di menu Pengaturan untuk cadangan.

Pengaturan QRIS

Unggah foto/hasil tangkapan layar kode QRIS statis dari aplikasi bank atau e-wallet Anda. Kode tampil di kasir dan di layar pelanggan.

Data & Cadangan

Cadangan seluruh data (menu, bahan, transaksi, biaya, akun) sebagai berkas JSON. Gunakan saat pindah browser/HP.

Catatan teknis QRIS
  • File lokal ini tidak bisa mendeteksi uang masuk secara otomatis; konfirmasi dilakukan oleh kasir.
  • Untuk status "sudah dibayar" otomatis, dibutuhkan gateway seperti Midtrans/Xendit atau QRIS merchant ber-webhook, plus database cloud.
  • Saat ini layar kasir dan pelanggan berbagi data di browser/perangkat yang sama.

# ☕ Sistem Penjualan & Stok Kafe

Aplikasi sederhana berbasis web untuk mengelola penjualan, stok bahan baku, dan riwayat transaksi di kafe. Dibuat khusus untuk UMKM kafe agar operasional lebih mudah dan terorganisir.

---

## ✨ Fitur Utama

- 📦 **Manajemen Bahan Baku** — Catat stok, satuan, dan harga bahan baku
- 📋 **Data Menu** — Daftar menu lengkap dengan resep dan takaran bahan
- 🛒 **Penjualan** — Transaksi cepat, pilih menu, masukkan nama kasir, cetak struk
- 📊 **Riwayat Penjualan** — Lihat laporan harian, siapa yang melayani, dan jumlah terjual
- 🔄 **Stok Otomatis** — Stok berkurang otomatis saat ada penjualan
- 🖨️ **Struk Penjualan** — Cetak struk lengkap dengan waktu transaksi

---

## 🚀 Cara Menggunakan

1. Buka file `index.html` di peramban web
2. Masukkan data bahan baku terlebih dahulu
3. Tambahkan menu lengkap dengan takaran bahan
4. Mulai transaksi penjualan
5. Lihat riwayat dan laporan penjualan kapan saja

> Data tersimpan otomatis di perangkat Anda, tidak perlu server tambahan.
